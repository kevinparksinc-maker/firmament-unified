# God–Agent No-Call Historical Evaluation Protocol

## Purpose

This document defines a **descriptive historical check**, not a betting system. It asks whether eligible games that produce a standard-orientation `god-agent-family-flow-v1` **No call** have a different observed underdog win rate from the overall eligible sample. It does not redefine `No call` as an underdog pick, change the frozen God-axis sectors, select an inverse orientation, tune a threshold after results, or recommend a wager.

## Frozen Evaluation Set

The evaluation will use the first **30 consecutive completed MLB regular-season games** in reverse chronological scheduled-start order for which every required pregame and final-record field can be verified. Collection begins with the most recently completed 2026 MLB regular-season games available when the study is run. Games are skipped, with a written exclusion reason, only when a required field cannot be verified. Any replacement game is the next chronological eligible game; it is never selected for its outcome or calculation result.

| Required field | Source and rule |
|---|---|
| Game identity, scheduled start, venue, teams, final score | Official MLB game feed / Stats API record |
| UTC instant | Converted from the scheduled local venue time and IANA venue time zone |
| Stadium coordinates | Official MLB venue record, supplemented only by a documented venue coordinate source if the official feed omits coordinates |
| Pregame favorite and challenger | A dated pregame market source showing a two-sided moneyline or clearly identifying the favorite |
| Underdog winner flag | The recorded challenger won the final score |
| God–Agent result | Re-run unchanged `god-agent-family-flow-v1`, standard orientation only |

Postgame recaps, result-driven favorite designations, forecasts, and team-strength rankings are not substitutes for a dated pregame market source. Inverse orientation is recorded only if already generated by the method, but is excluded from this analysis because it is mechanically complementary and audit-only.

## Measures

| Measure | Definition |
|---|---|
| Eligible sample size | Number of games satisfying every required field |
| No-call rate | No-call games divided by eligible games |
| Overall underdog win rate | Eligible games won by their recorded pregame underdog divided by eligible games |
| No-call underdog win rate | No-call games won by their recorded pregame underdog divided by no-call games |
| Directional-result underdog win rate | Non-no-call eligible games won by their recorded pregame underdog divided by directional-result games |
| Difference from baseline | No-call underdog win rate minus overall underdog win rate |

The report will provide the raw numerators and denominators and an exploratory Wilson 95% interval for each win rate. Given the small fixed sample, no result will be described as validation, predictive edge, calibration, or evidence to take a betting position.

## Interpretation Boundary

> A No call means that this frozen method did not establish the convergence required for a directional public result. It is not, by definition, an underdog signal.

If the observed no-call underdog win rate differs from the overall sample, that is a hypothesis-generating result that requires an independently frozen larger holdout. If it does not differ, the suggested interpretation is not supported in this sample. In both cases, the app continues to display **No call** unless a separately versioned, predeclared, and independently validated rule is later adopted.
